# مخزون الصالون

نظام ويب لإدارة مستهلكات الصالون: الأصناف، وفواتير الشراء، والصرف، والتالف، والتنبيهات، والتقارير.

## المبدأ الأساسي

**المخزون لا يزيد إلا بفاتورة شراء معتمدة.** أي موظفة تستطيع إدخال فاتورة كمسودة، ولا تُضاف الكميات للمخزون إلا بعد اعتمادها من مديرة النظام. كل حركة (شراء، صرف، تالف، منتهي) مسجلة باسم من قام بها ولا يمكن تعديلها أو حذفها.

## الصلاحيات

| الدور | الصلاحيات |
|---|---|
| مديرة النظام | كل شيء: الأصناف، الفئات، الموردين، المستخدمين، اعتماد الفواتير، التقارير والتكاليف |
| شريكة | عرض كل البيانات والتقارير والتكاليف، إدخال فواتير مسودة، تسجيل الصرف |
| موظفة | تسجيل الصرف والتالف، إدخال فواتير مسودة، عرض الأرصدة بدون أسعار، وترى حركاتها وفواتيرها فقط |

الصلاحيات مطبقة في قاعدة البيانات نفسها (Row Level Security ودوال محمية)، وليس في الواجهة فقط.

## التقنية

- واجهة ثابتة (HTML/CSS/JavaScript بدون أدوات بناء) منشورة على GitHub Pages.
- قاعدة البيانات وتسجيل الدخول وتخزين صور الفواتير على Supabase.
- `assets/config.js` يحتوي رابط المشروع والمفتاح العام (publishable) المصمم للاستخدام في الواجهة.
- `vendor/supabase.js` نسخة محلية من مكتبة supabase-js.

## دخول المستخدمين

تنشئ مديرة النظام حسابات الموظفات من صفحة «المستخدمين» باسم مستخدم وكلمة مرور، وتدخل الموظفة باسم المستخدم مباشرة.
