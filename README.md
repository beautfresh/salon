# مخزون الصالون

نظام ويب لإدارة مستهلكات الصالون: الأصناف، وفواتير الشراء، والصرف، والتالف، والتنبيهات، والتقارير.

## المبدأ الأساسي

**المخزون لا يزيد إلا بفاتورة شراء معتمدة.** أي موظفة تستطيع إدخال فاتورة كمسودة، ولا تُضاف الكميات للمخزون إلا بعد اعتمادها من مدير النظام. كل حركة (شراء، صرف، تالف، منتهي) مسجلة باسم من قام بها ولا يمكن تعديلها أو حذفها.

## الصلاحيات

| الدور | الصلاحيات |
|---|---|
| مدير النظام | كل شيء: الأصناف، الفئات، الموردين، المستخدمين، اعتماد الفواتير، التقارير والتكاليف |
| شريك | عرض كل البيانات والتقارير والتكاليف، إدخال فواتير مسودة، تسجيل الصرف |
| موظف | تسجيل الصرف والتالف، إدخال فواتير مسودة، عرض الأرصدة بدون أسعار، وترى حركاتها وفواتيرها فقط |

الصلاحيات مطبقة في قاعدة البيانات نفسها (Row Level Security ودوال محمية)، وليس في الواجهة فقط.

## التقنية

- واجهة ثابتة (HTML/CSS/JavaScript بدون أدوات بناء) منشورة على GitHub Pages.
- قاعدة البيانات وتسجيل الدخول وتخزين صور الفواتير على Supabase.
- `assets/config.js` يحتوي رابط المشروع والمفتاح العام (publishable) المصمم للاستخدام في الواجهة.
- `vendor/supabase.js` نسخة محلية من مكتبة supabase-js.

## دخول المستخدمين

- أي شخص يسجّل من صفحة «إنشاء حساب» بالاسم والبريد وكلمة المرور، ويبقى حسابه موقوفاً بدون أي وصول للبيانات.
- يظهر الطلب لمدير النظام في صفحة «المستخدمين» ليعتمده ويحدد صلاحيته، أو يرفضه.
- يمكن لمدير النظام أيضاً إضافة مستخدم مباشرة باسم مستخدم وكلمة مرور.

إعدادات Supabase المطلوبة (Authentication → Sign In / Providers): تفعيل «Allow new users to sign up»، وإيقاف «Confirm email».
